# Aster v0.9 Compiler Inspection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `aster check <entry> --format=json` (v0.9a) and `aster inspect <entry>` (v0.9b): one versioned JSON
contract giving coded diagnostics with exact file-local ranges, and, for a program that checks, every declaration with
its location, resolved type and signature.

**Architecture:** Codes are added to `Diag`/`LexError` at every producer. `asterc.aster:main` gets a `front_end`
that both the unchanged human reporter and a new JSON reporter render from. `json.aster` writes JSON; `inspect.aster`
converts global spans to file-local ranges and builds the response. For v0.9b the checker records a `LocalSite` per
allocated local (parallel to `ctx.locals`); top-level declarations are joined from the parser's items and the checked
program by name.

**Tech Stack:** Aster (the compiler in `packages/asterc-self/`), vitest 5 suites in `tests/` (TypeScript, Node ≥ 24),
pnpm.

**Spec:** `docs/superpowers/specs/2026-10-06-aster-v0.9-inspection-design.md`. Read it first; this plan argues from it.

## Global Constraints

- Schema string is exactly `aster/1`. One line of compact JSON plus `\n` on stdout; stderr empty for every handled
  JSON run.
- Human output of `aster check/build/run` stays byte-identical. The only intended human-golden change is the usage
  text.
- Exit statuses: 0 success, 1 diagnostics (incl. root malformed UTF-8), 2 root unreadable and usage errors, 101 panic.
- Ranges: half-open zero-based byte offsets into on-disk bytes (BOM included); lines 1-based, only `\n` breaks;
  columns 1-based UTF-16 units, BOM not counted; end clamped to the file.
- No new language features or builtins inside `packages/asterc-self/` (two-step rule).
- Compiler source rules: Aster has no closures, no default args, flat imports; follow the surrounding comment density
  and naming. New library files start with `// expect-library`.
- Every new suite is stage-aware (`stage()` from `tests/stage.ts`) and is added to `STAGE_SUITES` in
  `scripts/selfhost.ts`; new golden-writing suites are added to the `golden` script in `package.json`.
- Commits: conventional (`feat:`, `test:`, `docs:`), ending with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Prerequisite once per worktree: `pnpm install && pnpm bootstrap` (builds `build/asterc` from the nearest release).
  `pnpm test` builds S1 from the working tree in global setup.

## Review Focus

1. **A diagnostic at EOF in a file without a final newline** (unclosed `{`): the range must be zero-width at the file's
   byte length, line/col on the last line, not past it. Pinned by fixture `eof-no-newline` (Task 3).
2. **CRLF files**: `\r` is a column, not a line break; the human formatter strips it from the displayed line but the
   JSON column must still count everything before the start. Pinned by fixture `crlf` (Task 3).
3. **An error in an imported file whose base is not 0**: offsets must be file-local, not global. Pinned by
   `imported-error` and by the consumer test slicing bytes (Tasks 3, 5).
4. **Shadowing a parameter in a nested block and re-shadowing**: `shadows` must point at the immediately visible
   binding, not the first one. Pinned by fixture `shadowing` (Task 4).
5. **`inspect` on the compiler's own source**: large output must be fast (no quadratic joins) and deterministic.
   Pinned by the `self` case in Task 4 (runs twice, compares bytes, asserts it finishes within the suite timeout).

```ts
import { readdirSync, readFileSync } from 'node:fs';
import { join } from 'node:path';
import { describe, expect, it } from 'vitest';
import { REPO_ROOT } from './golden.js';

// Every diagnostic code the compiler can emit is catalogued in docs/inspect/README.md, and every catalogued code is
// emitted somewhere: the set of code literals in packages/asterc-self/ equals the catalogue. Codes are literals at their
// producers (spec §4), so a scan finds them all.

const PHASES = ['io', 'source', 'lex', 'syntax', 'import', 'decl', 'generic', 'typeref', 'main', 'flow', 'name', 'type', 'try', 'match', 'pattern', 'assign', 'call'];
const CODE = new RegExp(`"((?:${PHASES.join('|')})\\.[a-z0-9-]+)"`, 'g');

function sourceCodes(): Set<string> {
  const dir = join(REPO_ROOT, 'packages', 'asterc-self');
  const found = new Set<string>();
  for (const f of readdirSync(dir).filter((n) => n.endsWith('.aster'))) {
    for (const m of readFileSync(join(dir, f), 'utf8').matchAll(CODE)) {
      if (!m[1]!.endsWith('.aster')) found.add(m[1]!);
    }
  }
  return found;
}

function catalogue(): string[] {
  const text = readFileSync(join(REPO_ROOT, 'docs', 'inspect', 'README.md'), 'utf8');
  return [...text.matchAll(/^\| `([a-z]+\.[a-z0-9-]+)` \|/gm)].map((m) => m[1]!);
}

describe('diagnostic codes', () => {
  it('are catalogued once each', () => {
    const codes = catalogue();
    expect(codes.length).toBeGreaterThan(80);
    expect(new Set(codes).size).toBe(codes.length);
  });

  it('match the catalogue exactly', () => {
    expect([...sourceCodes()].toSorted()).toEqual(catalogue().toSorted());
  });

  it('are dotted kebab-case names in a known phase', () => {
    for (const c of catalogue()) expect(c).toMatch(new RegExp(`^(${PHASES.join('|')})\\.[a-z][a-z0-9-]*$`));
  });
});
```

`invalid_range` is defined in Task 2; in this task add it now in `loader.aster` (Task 2 then only adds its tests):

```aster
// A line and a UTF-16 column, both 1-based.
struct Pos {
    line: int,
    col: int,
}

// UTF-16 code units in src[from..to): one per UTF-8 lead byte, two for a 4-byte sequence's lead, none for a
// continuation byte.
fn utf16_units(src: string, from: int, to: int): int {
    var n: int = 0;
    for i in from..to {
        let b: int = byte_at(src, i);
        if b < 128 || b >= 192 {
            n += 1;
            if b >= 240 {
                n += 1;
            }
        }
    }
    return n;
}

// The line and column of offset `at` in `src` (BOM-stripped). Only `\n` ends a line.
fn file_pos(src: string, at: int): Pos {
    var line: int = 1;
    var line_start: int = 0;
    for i in 0..at {
        if byte_at(src, i) == '\n' {
            line += 1;
            line_start = i + 1;
        }
    }
    return Pos { line: line, col: 1 + utf16_units(src, line_start, at) };
}

// The range of src[start..end) (offsets into the BOM-stripped `src`; `bom` bytes were stripped), the end clamped to
// the file and the start to the end.
fn file_range(src: string, bom: int, start: int, end: int): Range {
    let e: int = min(end, len(src));
    let s: int = min(start, e);
    let a: Pos = file_pos(src, s);
    let b: Pos = file_pos(src, e);
    return Range { start: s + bom, end: e + bom, start_line: a.line, start_col: a.col, end_line: b.line, end_col: b.col };
}

// The one-byte range of the first ill-formed byte, at offset `at` of the raw (BOM-included) file `raw`: line and column
// count the well-formed bytes before it, and the byte itself is one column wide.
fn invalid_range(raw: string, at: int): Range {
    let bom: int = bom_len(raw);
    let p: Pos = file_pos(substring(raw, bom, len(raw)), at - bom);
    return Range { start: at, end: at + 1, start_line: p.line, start_col: p.col, end_line: p.line, end_col: p.col + 1 };
}
```

```aster
// expect-library
// The JSON writer behind `check --format=json` and `inspect` (docs/inspect/README.md): compact and deterministic, with
// no parser. Values are built as strings; `json_join` joins by halves, so long arrays stay O(n log n).

import "loader.aster";

fn json_hex_digit(n: int): string {
    return substring("0123456789abcdef", n, n + 1);
}

// `s` as a JSON string: `"` and `\` escaped, LF, CR and TAB as `\n`, `\r`, `\t`, other bytes below 0x20 and 0x7f as
// `\u00XX`, everything else (UTF-8 included) as is.
fn json_str(s: string): string {
    var out: string = "\"";
    var run: int = 0;
    for i in 0..len(s) {
        let b: int = byte_at(s, i);
        var esc: string = "";
        if b == '"' {
            esc = "\\\"";
        } else if b == '\\' {
            esc = "\\\\";
        } else if b == '\n' {
            esc = "\\n";
        } else if b == '\r' {
            esc = "\\r";
        } else if b == '\t' {
            esc = "\\t";
        } else if b < 32 || b == 127 {
            esc = "\\u00" + json_hex_digit(b / 16) + json_hex_digit(b % 16);
        } else {
            continue;
        }
        out += substring(s, run, i) + esc;
        run = i + 1;
    }
    return out + substring(s, run, len(s)) + "\"";
}

// The length of the maximal subpart of an ill-formed sequence at `at` (Unicode §3.9): a lead byte and the continuation
// bytes it allows, up to the first that does not fit; 1 for a byte that cannot start a sequence.
fn utf8_subpart_len(s: string, at: int): int {
    let b: int = byte_at(s, at);
    var n: int = 0;
    var lo: int = 128;
    var hi: int = 191;
    if b >= 194 && b <= 223 {
        n = 2;
    } else if b >= 224 && b <= 239 {
        n = 3;
        if b == 224 {
            lo = 160;
        }
        if b == 237 {
            hi = 159;
        }
    } else if b >= 240 && b <= 244 {
        n = 4;
        if b == 240 {
            lo = 144;
        }
        if b == 244 {
            hi = 143;
        }
    } else {
        return 1;
    }
    var k: int = 1;
    while k < n && at + k < len(s) {
        let c: int = byte_at(s, at + k);
        let min_c: int = if k == 1 { lo } else { 128 };
        let max_c: int = if k == 1 { hi } else { 191 };
        if c < min_c || c > max_c {
            break;
        }
        k += 1;
    }
    return k;
}

// `s` with each maximal ill-formed UTF-8 subpart replaced by U+FFFD: a path from argv need not be UTF-8, JSON text must.
fn utf8_lossy(s: string): string {
    var out: string = "";
    var run: int = 0;
    var i: int = 0;
    while i < len(s) {
        let bad: int = utf8_invalid_at(substring(s, i, len(s)));
        if bad == -1 {
            break;
        }
        let at: int = i + bad;
        out += substring(s, run, at) + "�";
        i = at + utf8_subpart_len(s, at);
        run = i;
    }
    return out + substring(s, run, len(s));
}

// parts[from..to) joined with commas, by halves.
fn json_join(parts: [string], from: int, to: int): string {
    if to - from == 0 {
        return "";
    }
    if to - from == 1 {
        return parts[from];
    }
    let mid: int = from + (to - from) / 2;
    return json_join(parts, from, mid) + "," + json_join(parts, mid, to);
}

fn json_array(parts: [string]): string {
    return "[" + json_join(parts, 0, len(parts)) + "]";
}

// `fields` are `json_kv` pairs, in output order.
fn json_object(fields: [string]): string {
    return "{" + json_join(fields, 0, len(fields)) + "}";
}

fn json_kv(key: string, value: string): string {
    return json_str(key) + ":" + value;
}

fn json_bool(b: bool): string {
    return if b { "true" } else { "false" };
}

fn json_int(n: int): string {
    return int_to_string(n);
}
```

```aster
// expect-library
// The front end of a `check`, `build`, `run` or `inspect`: read the root, check it is UTF-8, load its closure, check
// it. Both the human reporter (asterc.aster) and the JSON one (inspect.aster) render its result, so they cannot
// disagree about what went wrong.

import "loader.aster";
import "checker.aster";

// `Unreadable`: the root file cannot be read. `Malformed`: its raw bytes, and the offset of the first ill-formed one.
// `Failed`: the loaded files and the load or check errors, unsorted; a program with load errors is not checked.
// `Passed`: the loaded files and the checked program.
enum FrontEnd {
    Unreadable,
    Malformed(string, int),
    Failed(Loaded, [Diag]),
    Passed(Loaded, Checked),
}

fn front_end(path: string): FrontEnd {
    let Result::Ok(src) = read_file(path) else {
        return FrontEnd::Unreadable;
    };
    let bad: int = utf8_invalid_at(src);
    if bad != -1 {
        return FrontEnd::Malformed(src, bad);
    }
    let loaded: Loaded = load_program(path, src);
    if len(loaded.diags) > 0 {
        return FrontEnd::Failed(loaded, loaded.diags);
    }
    let checked: Checked = check_program(loaded.items, loaded.root_end);
    if len(checked.diags) > 0 {
        return FrontEnd::Failed(loaded, checked.diags);
    }
    return FrontEnd::Passed(loaded, checked);
}

// The exit status of a run that stops after the front end: 2 for an unreadable root, 1 for any error, else 0.
fn front_end_status(fe: FrontEnd): int {
    return match fe {
        FrontEnd::Unreadable => 2,
        FrontEnd::Malformed(_, _) => 1,
        FrontEnd::Failed(_, _) => 1,
        FrontEnd::Passed(_, _) => 0,
    };
}
```

```aster
// expect-library
// The JSON response of `check --format=json` and `inspect` (docs/inspect/README.md, schema `aster/1`): files,
// diagnostics with file-local ranges, and, for `inspect`, the program's declarations.

import "frontend.aster";
import "report.aster";
import "json.aster";

// The index of the file a global offset falls in: the last one whose base is at or before it.
fn file_index(files: [SourceFile], start: int): int {
    var found: int = 0;
    for i in 0..len(files) {
        if files[i].base <= start {
            found = i;
        }
    }
    return found;
}

fn json_range(r: Range): string {
    return json_object([
        json_kv("start", json_int(r.start)), json_kv("end", json_int(r.end)),
        json_kv("start_line", json_int(r.start_line)), json_kv("start_col_utf16", json_int(r.start_col)),
        json_kv("end_line", json_int(r.end_line)), json_kv("end_col_utf16", json_int(r.end_col)),
    ]);
}

// The location fields `file`, `path`, `range` and, for a path that is not UTF-8, `path_exact`. `file` is a files
// index, or -1 for a file that never loaded.
fn location_fields(file: int, path: string, range: Option[Range]): [string] {
    let shown: string = utf8_lossy(path);
    let fields: [string] = [
        json_kv("file", if file < 0 { "null" } else { json_int(file) }),
        json_kv("path", json_str(shown)),
        json_kv("range", match range {
            Option::Some(r) => json_range(r),
            Option::None => "null",
        }),
    ];
    if shown != path {
        push(fields, json_kv("path_exact", "false"));
    }
    return fields;
}

fn json_location(file: int, path: string, range: Option[Range]): string {
    return json_object(location_fields(file, path, range));
}

// The range of global span [start, end) in the file it starts in.
fn global_range(files: [SourceFile], start: int, end: int): Range {
    let f: SourceFile = files[file_index(files, start)];
    return file_range(f.src, f.bom, start - f.base, end - f.base);
}

fn json_diagnostic(code: string, message: string, primary: string, related: [string]): string {
    return json_object([
        json_kv("code", json_str(code)), json_kv("severity", json_str("error")), json_kv("message", json_str(message)),
        json_kv("primary", primary), json_kv("related", json_array(related)),
    ]);
}

fn json_diag(files: [SourceFile], d: Diag): string {
    let fi: int = file_index(files, d.start);
    let primary: string = json_location(fi, files[fi].path, Option::Some(global_range(files, d.start, d.end)));
    let related: [string] = [];
    for r in d.related {
        let fields: [string] = [json_kv("role", json_str(r.role))];
        for f in location_fields(-1, r.path, r.range) {
            push(fields, f);
        }
        push(related, json_object(fields));
    }
    return json_diagnostic(d.code, d.message, primary, related);
}

fn json_files(files: [SourceFile]): string {
    let out: [string] = [];
    for i in 0..len(files) {
        let shown: string = utf8_lossy(files[i].path);
        let fields: [string] = [json_kv("id", json_int(i)), json_kv("path", json_str(shown)), json_kv("bom", json_bool(files[i].bom > 0))];
        if shown != files[i].path {
            push(fields, json_kv("path_exact", "false"));
        }
        push(out, json_object(fields));
    }
    return json_array(out);
}

// The whole response for `command` (`check` or `inspect`) on the root `path`, without a final newline.
fn inspect_response(command: string, path: string, fe: FrontEnd): string {
    var files: string = "[]";
    let diags: [string] = [];
    match fe {
        FrontEnd::Unreadable => {

        }
    }

        json_kv("files", files), json_kv("diagnostics", json_array(diags)),
    ];
    return json_object(fields);
}
```

```aster
fn declare(ctx: Ctx, name: Ident, ty: Type, mutable: bool): Local {

// Declares `name` in the innermost scope; [start, end) is the whole declaration, for `inspect`.
fn declare_at(ctx: Ctx, name: Ident, ty: Type, mutable: bool, start: int, end: int): Local {
    var shadows: int = -1;
    if let Option::Some(outer) = lookup(ctx, name.name) {
        shadows = outer.id;
    }
    let scope: Map[string, Local] = ctx.scopes[len(ctx.scopes) - 1];
    if let Option::Some(_) = map_get(scope, name.name) {
        report(ctx.env, "name.duplicate-local", "'" + name.name + "' is already declared in this scope", name.start, name.end);
    }
    let local: Local = Local { id: len(ctx.locals), name: name.name, ty: ty, mutable: mutable };
    push(ctx.locals, local);
    push(ctx.sites, LocalSite { name: name, start: start, end: end, shadows: shadows });
    map_set(scope, local.name, local);
    return local;
}
```

The walk (written once as `fn walk(w: Walk)` where `struct Walk { ids: Ids, render: bool, out: [string], loaded: Loaded, checked: Checked, … }`;
in the counting pass `render` is false and `walk` only advances `ids.next` and fills the maps; in the rendering pass it
pushes one JSON object per declaration to `out` and asserts `len(out)` equals the id it renders with
`panic("internal: inspect ids out of step")` otherwise):

1. **Source**, for each item of `loaded.items` in order:
   - `Item::Fn(d)`: `fn` (location `d.name`, decl range `d.start..d.end`, `signature` from the `TFunction` with the
     same name: params = its first `params` locals with names, types and the param fact ids; `ret`). Then its
     locals: the `FnSites` whose `name.start == d.name.start`, ordered by `site.name.start` (insertion-sort a list of
     local ids); local `k` with `k < params` is a `param` (`type`, `scope`), otherwise a `local` (`type`, `mutable`,
     `scope`, `shadows` = the fact id of local `site.shadows`, or `null`). Fact id of local `k` = fn id + 1 + its
     position in that order (build a `[int]` from local id to position first).
   - `Item::Struct(d)`: `struct` (location `d.name`, range `d.start..d.end`), then each field: `field` (location
     `field.name`, range `field.name.start..field.ty.end`, `type` from the `TStruct`'s field of that name, `parent`).
   - `Item::Enum(d)` without params: `enum`, then each variant: `variant` (location `v.name`, range
     `v.name.start..(last payload's end, or v.name.end)`, `payload` from the `TEnum`, `parent`).
   - `Item::Enum(d)` with params: `enum` with `type_params` = the ids of the `type-param` facts that follow, then each
     param (`type-param`, location and range = the param `Ident`, `parent`), then each variant with `payload` from
     `json_type_expr(…, d.params)`.
   - `Item::Import(_)`: nothing.
2. **Prelude**: for each template of `prelude_templates()`: same as a generic enum, `origin:"prelude"`, every
   `location`/`decl_range` `null`.
3. **Instantiations**: each `checked.enums` entry with `base != ""`, in order: `enum` with `origin:"instantiation"`,

4. **Builtins**: `builtin_names()` in order: `builtin-type` or `builtin-fn` (`signature` from `builtin_signatures()`

```aster
        Type::Void => json_prim("void"),

        Type::Map(k, v) => json_object([json_kv("kind", json_str("map")), json_kv("key", json_type(ids, checked, k)), json_kv("value", json_type(ids, checked, v))]),
```

`void`/`never` → primitives; `Map`/`Set` → map/set of the converted args; a struct → `json_named("struct", …)`;
another name with args → `{"kind":"enum","name":<display>,"decl":ids.types[name],"args":[…]}` where display is

```ts
// The acceptance test of issue #53: a consumer that knows only the public JSON contract (docs/inspect/README.md). It
// never reads stderr or human text, and takes positions only from `range` byte offsets.

const dir = mkdtempSync(join(tmpdir(), 'aster-consumer-'));
afterAll(() => rmSync(dir, { recursive: true, force: true }));

function aster(argv: string[]) {
  const r = spawnSync(stage().bin, argv, { cwd: dir, env: { ...process.env, LC_ALL: 'C' }, timeout: 60_000 });
  if (r.error) throw r.error;
  return { status: r.status, doc: JSON.parse(r.stdout.toString('utf8')) };
}

function slice(path: string, range: { start: number; end: number }): string {
  return readFileSync(join(dir, path)).subarray(range.start, range.end).toString('utf8');
}

const MAIN = 'import "geometry.aster";\n\nfn main(): int {\n    let p: Point = origin();\n    return area(p, 3);\n}\n';
const BROKEN = '// Shapes 📐\nstruct Point {\n    x: int,\n    y: int,\n}\n\nfn origin(): Point {\n    return Point { x: 0, y: 0 };\n}\n\nfn area(p: Point, side: int): int {\n    return p.z * side;\n}\n';
const FIXED = BROKEN.replace('p.z', 'p.x');

describe('an external consumer', () => {
  it('finds a broken field access by code and exact range, without human text', () => {
    writeFileSync(join(dir, 'main.aster'), MAIN);
    writeFileSync(join(dir, 'geometry.aster'), BROKEN);
    const { status, doc } = aster(['check', 'main.aster', '--format=json']);
    expect(status).toBe(1);
    expect(doc.schema).toBe('aster/1');
    const d = doc.diagnostics.find((x: any) => x.code === 'name.unknown-field');
    expect(d).toBeDefined();
    const file = doc.files[d.primary.file];
    expect(file.path.endsWith('geometry.aster')).toBe(true);
    expect(slice(file.path, d.primary.range)).toBe('z');
    expect(d.primary.range.start_line).toBe(12);
  });

  it('reads the fixed program\'s declaration, signature and location', () => {
    writeFileSync(join(dir, 'geometry.aster'), FIXED);
    const { status, doc } = aster(['inspect', 'main.aster']);
    expect(status).toBe(0);
    expect(doc.semantics.available).toBe(true);
    const decls = doc.semantics.declarations;
    const area = decls.find((x: any) => x.kind === 'fn' && x.name === 'area');
    const point = decls.find((x: any) => x.kind === 'struct' && x.name === 'Point');
    expect(area.signature.ret).toEqual({ kind: 'int' });
    expect(area.signature.params.map((p: any) => [p.name, p.type])).toEqual([
      ['p', { kind: 'struct', name: 'Point', decl: point.id }],
      ['side', { kind: 'int' }],
    ]);
    const path = doc.files[area.location.file].path;
    expect(slice(path, area.location.range)).toBe('area');
    expect(slice(path, area.decl_range).startsWith('fn area(')).toBe(true);
    const p = decls.find((x: any) => x.kind === 'local' && x.name === 'p');
    expect(p.type).toEqual({ kind: 'struct', name: 'Point', decl: point.id });
    expect(decls[p.scope].name).toBe('main');
  });
});
```
