# Aster v0.8 Maps and Sets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add built-in `Map[K, V]` and `Set[K]` types (keys `int` or `string`), a context-typed `{}`, and the nine `map_*`/`set_*` builtins, on both backends (v0.8a, Tasks 1–6). Then rewrite the compiler onto them (v0.8b, Task 7, a separate PR after v0.8a's release).

**Architecture:** An insertion-ordered hash table in the C runtime (`aster_rt_map_*`). The checker gets `Type::Map`/`Type::Set` and builtin typing. Lowering adds `Map*` IR instructions, and `map_get` builds its `Option` in lowering. Both emitters turn the instructions into runtime calls. The design follows arrays at every layer.

**Tech Stack:** Aster (packages/asterc-self), C11 runtime, vitest, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-05-aster-v0.8-maps-sets-design.md`

## Global Constraints

- **Two-step rule:** in v0.8a, no file in `packages/asterc-self/` may *use* `Map`, `Set`, `{}` or any `map_*`/`set_*` builtin in its own code. It may implement them. `release-bootstrap` CI enforces this.
- Keys are `int` or `string` only. `V` is any type except `void`.
- Iteration (`map_keys`, `set_items`) is in insertion order. Overwriting keeps the position. Remove-then-add goes to the end.
- Exact diagnostics (spec §2):
  - `map key must be int or string, found <T>`
  - `map value cannot be void`
  - `'Map' expects 2 type argument(s), got <n>` / `'Set' expects 1 type argument(s), got <n>`
  - `'Map' is a builtin type and cannot be redefined` (and `'Set' ...`)
  - `cannot infer type of empty map or set`
  - `type mismatch: expected <T>, found empty map or set`
  - `function '<name>' expects a map, found <T>` / `function '<name>' expects a set, found <T>`
  - `function 'len' expects a string, array, map or set, found <T>`
  - plus the existing arity, `type mismatch`, `cannot compare`, `cannot print` and `is a builtin function` messages
- Types print as `Map[K, V]` and `Set[K]` (`, ` between arguments).
- The runtime is warning-clean under `cc -std=c11 -O2 -Wall -Wextra -Werror`. After any runtime edit, run `pnpm gen:runtime` (`tests/runtime_aster.test.ts` fails on a stale `runtime.aster`).
- Every new `aster_rt_*` function has a matching `declare` in `emit_llvm.aster`'s `llvm_runtime_declarations`, because `tests/llvm_backend.test.ts` checks them against `aster_rt.h`.
- **v0.8a goldens:** preserve existing expectations except the two narrow changes accepted in [PR #50](https://github.com/foestauf/aster/pull/50): the extended `len` diagnostic (the `array_errors` and `check_unwrap` expectations), and typed summaries whose input includes changed compiler source, directly or through imports. The latter reflect source changes, not a change to the compiler's behaviour on unchanged input. New corpus files add new goldens, and `tests/golden/accepted.txt` gains the new accepted programs, in sorted order, by hand.
- **Golden review:** new goldens and the exceptions above must be individually reviewed against their inputs. Identify each changed existing snapshot and the specific diagnostic or source edit that requires it in the PR. Retain only the minimal justified hunks; no blanket regeneration may hide changes to unchanged user-program behaviour, diagnostics, ordering, stdout, stderr or exit status. Task 7 defines the narrower v0.8b exception; the v0.8a `len` change is already part of that baseline.
- Local environment: `tests/llvm_backend.test.ts` and `pnpm selfhost` need clang 18. On machines without it, those fail or can't run, and CI's `proof (SL1)` and `full` legs are the evidence.
- Conventional commits ending with the session's attribution lines.

## Review Focus

1. **Hash collisions and tombstones:** two keys with the same index slot, removal of the first, then a lookup of the second must still find it. Task 1's C harness forces collisions by using a tiny table.
2. **`{}` at statement start** must stay an empty block (`{}` alone on a line inside a function). Task 2 adds a corpus program with a bare `{}` block statement next to a `{}` expression.
3. **Map values that are strings (16 bytes) or structs (pointers) on LLVM:** slot read and write sizes must use `llvm_size(V)`. Task 5's corpus covers string, struct, array, enum and nested-map values on both backends.
4. **`map_get` on a missing key, then the payload-free path:** `Option::None` must not read the slot. Task 4 lowers through a has-branch, and Task 5's programs exercise it.
5. **The two-step rule:** Task 6's guard greps `packages/asterc-self/*.aster` for `Map[`, `Set[`, `map_` and `set_` in non-comment code (excluding the builtin-name string tables and the checker/lower/emit implementation), so a premature use fails locally before CI.

- [ ] **Step 2: Implement in `aster_rt.c`** (near the array functions; reuse `aster_rt_alloc`, which panics `out of memory`):

```c
typedef struct {
  uint64_t hash;
  int64_t live;
  int64_t ikey;
  aster_string skey;
} aster_map_entry; /* followed by value_size bytes, rounded up to 8 */

struct aster_map_obj {
  int64_t key_kind, value_size, stride;
  int64_t count;     /* live entries */
  int64_t used;      /* entries appended since the last rebuild, live or dead */
  int64_t cap;       /* index slots (power of two); entries hold up to cap */
  char *entries;
  int32_t *index;    /* -1 = empty, else an entry number */
};

#define MAP_ENTRY(m, i) ((aster_map_entry *)((m)->entries + (i) * (m)->stride))
#define MAP_VALUE(e) ((void *)((char *)(e) + sizeof(aster_map_entry)))

static uint64_t map_hash(const struct aster_map_obj *m, int64_t ikey, aster_string skey) {
  if (m->key_kind == ASTER_KEY_STRING) {
    uint64_t h = 1469598103934665603ULL;
    for (int64_t i = 0; i < skey.len; i++) { h ^= (unsigned char)skey.ptr[i]; h *= 1099511628211ULL; }
    return h;
  }
  uint64_t x = (uint64_t)ikey + 0x9e3779b97f4a7c15ULL;
  x = (x ^ (x >> 30)) * 0xbf58476d1ce4e5b9ULL;
  x = (x ^ (x >> 27)) * 0x94d049bb133111ebULL;
  return x ^ (x >> 31);
}

static int map_key_eq(const struct aster_map_obj *m, const aster_map_entry *e, int64_t ikey, aster_string skey) {
  if (m->key_kind == ASTER_KEY_STRING)
    return e->skey.len == skey.len && (skey.len == 0 || memcmp(e->skey.ptr, skey.ptr, (size_t)skey.len) == 0);
  return e->ikey == ikey;
}

/* The entry number for the key, or -1; *slot gets the index slot where it is or would go. */
static int64_t map_find(const struct aster_map_obj *m, uint64_t h, int64_t ikey, aster_string skey, uint64_t *slot) {
  uint64_t mask = (uint64_t)m->cap - 1;
  for (uint64_t s = h & mask;; s = (s + 1) & mask) {
    int32_t n = m->index[s];
    if (n < 0) { *slot = s; return -1; }
    aster_map_entry *e = MAP_ENTRY(m, n);
    if (e->live && e->hash == h && map_key_eq(m, e, ikey, skey)) { *slot = s; return n; }
  }
}

/* Copies the live entries, in order, into a table of new_cap slots and rebuilds the index. */
static void map_rebuild(struct aster_map_obj *m, int64_t new_cap) {
  char *entries = aster_rt_alloc(new_cap * m->stride);
  int64_t w = 0;
  for (int64_t r = 0; r < m->used; r++) {
    aster_map_entry *e = MAP_ENTRY(m, r);
    if (e->live) { memcpy(entries + w * m->stride, e, (size_t)m->stride); w++; }
  }
  m->entries = entries;
  m->used = w;
  m->cap = new_cap;
  m->index = aster_rt_alloc(new_cap * (int64_t)sizeof(int32_t));
  memset(m->index, 0xff, (size_t)new_cap * sizeof(int32_t));
  uint64_t mask = (uint64_t)new_cap - 1;
  for (int64_t i = 0; i < w; i++) {
    uint64_t s = MAP_ENTRY(m, i)->hash & mask;
    while (m->index[s] >= 0) s = (s + 1) & mask;
    m->index[s] = (int32_t)i;
  }
}

aster_map aster_rt_map_new(int64_t key_kind, int64_t value_size) {
  struct aster_map_obj *m = aster_rt_alloc((int64_t)sizeof(struct aster_map_obj));
  m->key_kind = key_kind;
  m->value_size = value_size;
  m->stride = (int64_t)sizeof(aster_map_entry) + ((value_size + 7) & ~(int64_t)7);
  m->used = 0;
  map_rebuild(m, 8);
  return m;
}

void *aster_rt_map_slot(aster_map m, int64_t ikey, aster_string skey, int64_t create) {
  uint64_t h = map_hash(m, ikey, skey), s;
  int64_t n = map_find(m, h, ikey, skey, &s);
  if (n >= 0) return MAP_VALUE(MAP_ENTRY(m, n));
  if (!create) return NULL;
  if ((m->used + 1) * 3 > m->cap * 2) {
    /* Grow only if the live entries need it; otherwise the rebuild just drops tombstones. */
    map_rebuild(m, (m->count + 1) * 3 > m->cap ? m->cap * 2 : m->cap);
    map_find(m, h, ikey, skey, &s);
  }
  aster_map_entry *e = MAP_ENTRY(m, m->used);
  e->hash = h;
  e->live = 1;
  e->ikey = ikey;
  e->skey = skey;
  memset(MAP_VALUE(e), 0, (size_t)(m->stride - (int64_t)sizeof(aster_map_entry)));
  m->index[s] = (int32_t)m->used;
  m->used++;
  m->count++;
  return MAP_VALUE(e);
}

int64_t aster_rt_map_insert(aster_map m, int64_t ikey, aster_string skey) {
  int64_t before = m->count;
  aster_rt_map_slot(m, ikey, skey, 1);
  return m->count != before;
}

int64_t aster_rt_map_remove(aster_map m, int64_t ikey, aster_string skey) {
  uint64_t s;
  int64_t n = map_find(m, map_hash(m, ikey, skey), ikey, skey, &s);
  if (n < 0) return 0;
  MAP_ENTRY(m, n)->live = 0;
  m->count--;
  return 1;
}

int64_t aster_rt_map_len(aster_map m) { return m->count; }

aster_array aster_rt_map_keys(aster_map m) {
  int64_t size = m->key_kind == ASTER_KEY_STRING ? (int64_t)sizeof(aster_string) : (int64_t)sizeof(int64_t);
  aster_array a = aster_rt_array_new(size, m->count);
  int64_t w = 0;
  for (int64_t r = 0; r < m->used; r++) {
    aster_map_entry *e = MAP_ENTRY(m, r);
    if (!e->live) continue;
    if (m->key_kind == ASTER_KEY_STRING) *(aster_string *)aster_rt_array_at(a, w) = e->skey;
    else *(int64_t *)aster_rt_array_at(a, w) = e->ikey;
    w++;
  }
  return a;
}
```

Notes for the implementer:
- Check `aster_rt_array_new(elem_size, len)` really creates `len` zeroed elements. If it creates an empty array with capacity instead, use `push_slot`.
- Dead entries keep their index slot until the next rebuild, so probing passes over them. The `used` counter (not `count`) drives the load check.
- Memory is never freed (language rule).
