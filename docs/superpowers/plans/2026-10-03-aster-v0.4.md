# Aster v0.4: Literal Patterns, Character Literals, stderr and exit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add character literals, `match` on int/bool/string values with or-patterns, and `eprint`/`exit`, then dogfood all of it in `lex.aster` and `parse.aster`.

**Architecture:** Char literals are a new token kind that becomes an `int`-typed expression. Patterns become `wildcard | or | alternative`, and the checker generalises `checkMatch` over four scrutinee categories, producing a new `TPattern` union (`wildcard | variants | ints | strings`). Int, char and bool matches lower to the existing `switch` terminator (case values widen to `bigint`). String matches lower to a `str_eq` + `br` chain. `eprint` is typed like `print` and lowers to `eprint_*` runtime calls. `exit` is a signature builtin that diverges like `panic`.

**Tech Stack:** TypeScript (Node 24, pnpm, vitest, oxlint), C11 runtime compiled with the system `cc`. The self-hosted programs are Aster.

**Spec:** `docs/superpowers/specs/2026-10-03-aster-v0.4-design.md` (read it first; this plan argues from it).

## Review Focus

1. **`'` inside comments and strings.** `// don't` and `"it's"` must not start a char literal. Pinned by a lexer unit test in Task 1 and by `fixtures/lex_chars.txt` in Task 3.
2. **`||` vs `|`.** `a || b` stays one token; `1 | 2` is two alternatives; `1 || 2` in a pattern is a parse error (`expected '=>', found '||'`). Pinned in Task 1 (lexer) and Task 2 (parser).
3. **INT64_MIN and negative literals as cases.** `match x { -9223372036854775808 => …, -1 => …, _ => … }` must compile under `-Werror` and select correctly. Pinned by `match/int.aster` in Task 5.
4. **Strings with a shared prefix and the empty string.** `"=" | "=="` and `""` must be distinguished by full byte equality. Pinned by `match/string.aster` in Task 5.
5. **stdout/stderr ordering.** `print("a"); eprint("b"); exit(3);` must leave `a` on stdout (flushed even though `exit` skips `main`'s return) and `b` on stderr. Pinned by `io/eprint_exit.aster` in Task 6.

```ts
      // Scan to the closing quote on this line, honouring backslash escapes, so an error spans the whole literal.
      i++;
      let terminated = false;
      while (i < text.length && text[i] !== '\n') {
        if (text[i] === '\\' && i + 1 < text.length && text[i + 1] !== '\n') {
          i += 2;
          continue;
        }
        if (text[i] === "'") {
          i++;
          terminated = true;
          break;
        }
        i++;
      }
      const body = text.slice(start + 1, terminated ? i - 1 : i);
      let value = 0n;
      let error: Diagnostic | null = null;
      if (!terminated) {
        error = { message: 'unterminated character literal', span: { start, end: i } };
      } else if (body.length === 0) {
        error = { message: 'empty character literal', span: { start, end: i } };
      } else if (body[0] === '\\') {
        const mapped = body.length === 2 ? ESCAPES.get(body[1]) : undefined;
        if (body.length === 2 && mapped === undefined) {
          error = { message: `invalid escape sequence '${body}'`, span: { start: start + 1, end: start + 3 } };
        } else if (mapped === undefined) {
          error = { message: 'character literal must be a single ASCII character', span: { start, end: i } };
        } else {
          value = BigInt(mapped.charCodeAt(0));
        }
      } else if (body.length === 1 && body >= ' ' && body <= '~') {
        value = BigInt(body.charCodeAt(0));
      } else {
        error = { message: 'character literal must be a single ASCII character', span: { start, end: i } };
      }
      if (error !== null) diagnostics.push(error);
      push('char', start, { intValue: value });
      continue;
    }
```

A lone `\` before the newline (`'\` + newline) is not an escape: the scanner stops at the newline and reports `unterminated character literal`.

```ts
/** One alternative of a pattern. Literal `raw` fields hold the source text (`-5`, `'a'`, `"x"`). */
export type Alternative =
  | { kind: 'variant'; enumName: string; enumSpan: Span; variant: string; variantSpan: Span; binders: (Binder | null)[]; span: Span }
  | { kind: 'intPat'; value: bigint; raw: string; span: Span }
  | { kind: 'charPat'; value: bigint; raw: string; span: Span }
  | { kind: 'stringPat'; value: string; raw: string; span: Span }
  | { kind: 'boolPat'; value: boolean; span: Span };

/** `_`, one alternative, or two or more alternatives joined by `|`. Patterns are flat. */
export type Pattern =
  | { kind: 'wildcard'; span: Span }
  | { kind: 'or'; alternatives: Alternative[]; span: Span }
  | Alternative;
```

```ts
    const wildcard = eat('_');
    if (wildcard) return { kind: 'wildcard', span: wildcard.span };
    const alternatives = [parseAlternative()];
    while (eat('|')) alternatives.push(parseAlternative());
    if (alternatives.length === 1) return alternatives[0];
```

```ts
/** What a match arm accepts. Unresolved alternatives contribute no values; an arm with none is never taken. */
export type TPattern =
  | { kind: 'wildcard' }
  /** Enum variants. `binders` has one entry per payload slot when there is exactly one variant, else it is empty. */
  | { kind: 'variants'; variants: { name: string; tag: number }[]; binders: (Local | null)[] }
```
